# Secure Real Time Vision Systems Research Project

This repository contains the public article for my bachelor thesis, completed in collaboration with Axis Communications. The project investigates how metadata from multiple network cameras can be processed and visualized in real time while maintaining strong security and privacy principles. All implementation details are excluded due to NDA requirements.

## Research Overview

This project examines how real time metadata from distributed camera systems can be securely processed, aligned, and transformed into visual representations that support analysis, monitoring, and decision making. The research explores the challenges involved in receiving asynchronous metadata streams, mitigating privacy risks, and presenting information in a way that remains useful while respecting strict confidentiality requirements.

A central goal of the thesis was to design a conceptual framework for handling camera generated metadata in a secure and privacy aware manner. This included evaluating latency constraints, studying how metadata behaves across multiple camera viewpoints, and investigating visual abstraction techniques that make complex scenes easier to understand without exposing sensitive details.
The work explores how real time metadata can be transformed into meaningful visual insights without exposing sensitive information. The study covers secure data handling, timing constraints in distributed camera systems, and design considerations for building clear and interpretable visual representations of camera derived information.
